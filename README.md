# Humanitarian Affairs & IHL Briefing Hub

**Live site:** https://itemr.github.io/humanitarian-briefing-hub/

A personal project exploring how humanitarian affairs, UN Human Rights Council and international humanitarian law (IHL) information can be organised so that a colleague can prepare for a meeting quickly.

This is an independent project. It is not affiliated with, endorsed by or representative of the views of the ICRC, the UN or any other organisation.

## What It Contains
- **About This Hub:** What the hub is, how to use each section and how information is organised.
- **Weekly Briefing:** A short, printable briefing note explaining what happened, why it matters and where it comes from.
- **Contexts:** A searchable table of developments by context, colour-coded by humanitarian theme and forum, exportable to CSV.
- **HRC Monitoring:** A timeline of items at the 63rd session of the Human Rights Council.
- **IHL Resources:** A reference library colour-coded by resource type.

## Approach
All information comes from public sources, prioritising UN primary sources such as OHCHR and OCHA. Findings are attributed to the body that made them, and the wording is kept factual and neutral. Content is a fixed snapshot of October 1 2026, not a live update.

## Built With
HTML, CSS and JavaScript, hosted on GitHub Pages. The content is stored separately from the page layout, so it can be updated without changing the design.
